# UNITED

Voice-triggered emergency alert web app. Say "Stay Calm" or tap EMERGENCY, confirm SEND — UNITED captures your GPS location, records audio, and dispatches the alert.

## Features
- Voice trigger ("ALERT") + big EMERGENCY button
- GPS location captured with every alert
- Audio recording during alerts
- Owner panel (tap the title 5x) with optional $5/year subscription via Stripe
- Privacy Policy + Terms of Service built in

## Status
Currently in **TEST mode** — alerts go to a test relay only. Live EMS dispatch (RapidSOS integration) is in progress. UNITED is a supplemental tool, NOT a replacement for calling 911.
